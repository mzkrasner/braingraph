# External-System Assessment

Use these questions only for systems relevant to the user's current workflow.

1. What records or state does this system authoritatively own?
2. Is it a source, intake channel, execution system, communication system, reference, archive, or several of these?
3. Which stable record identifiers or URLs should be retained?
4. Is current state verified live, tracked by source revision, consumed as a dated snapshot, or not freshness-sensitive?
5. Can agents read through an approved connector, only through human-provided exports, or not at all?
6. Are writes prohibited, explicitly approval-gated, or delegated for a narrow workflow?
7. Should Braingraph link, summarize, synchronize, copy, or exclude its content?
8. Is the content public, private, confidential, or regulated?
9. What fallback is acceptable when the connector is absent or the evidence conflicts?

Prefer the least duplicative capture mode that still gives the knowledge workspace durable value.
