# External-System Assessment

Use these questions only for systems relevant to the user's current workflow.

1. What records or state does this system authoritatively own?
2. Is this integration active now, planned but not yet available, or intentionally inactive but retained for provenance?
3. Is it a source, intake channel, execution system, communication system, reference, archive, or several of these?
4. Which stable native record identifiers or URLs should be retained, and which display labels are unsafe as identity?
5. Is current state verified live, tracked by source revision, consumed as a dated snapshot, or not freshness-sensitive?
6. Can agents read through an approved connector, only through human-provided exports, or not at all?
7. Are writes prohibited, explicitly approval-gated, or delegated for a narrow workflow? If delegated, what exact actions and records are in scope?
8. Should Braingraph link, summarize, synchronize, copy, or exclude its content by default? What exceptions matter?
9. Is the content public, private, confidential, or regulated?
10. What must the agent do when the connector is absent, a record revision changes, or evidence conflicts?

Prefer the least duplicative capture mode that still gives the knowledge workspace durable value.
