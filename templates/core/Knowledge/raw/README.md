# Raw Intake

Use this directory for local, unsynthesized material awaiting review. Generated ignore rules keep raw files out of Git by default.

- Prefer links and stable source IDs when an external system owns the content.
- Do not place credentials or prohibited sensitive material here.
- Move successfully reviewed local inputs to `processed/`; never delete them implicitly.
- Durable conclusions belong in projects, domains, or wiki pages with provenance recorded under `sources/`.
