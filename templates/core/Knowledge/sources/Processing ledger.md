# Source Processing Ledger

Track source identity and revision state so agents do not repeatedly process unchanged material. Use stable native IDs or URLs rather than titles alone. Add or advance a row only after the corresponding review or authorized knowledge update succeeds. Valid dispositions include `pending`, `proposed`, `applied`, `no-change`, `blocked`, and `out-of-scope`.
